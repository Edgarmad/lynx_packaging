# Video de inicio

Video entregado y autorizado para la Home por el usuario el 4 de octubre de 2026: `IMG_3160.MOV`.

Se conserva el contenido y la duración (27.84 segundos) en una copia web H.264 MP4 de 1920 × 1080, sin pista de audio ni metadatos del archivo original, con faststart. El poster se extrae del segundo 1. Ambos assets se sirven localmente desde `public/images/home/` y se comparten entre español e inglés.

El hero reproduce en silencio y en bucle cuando el navegador lo permite. Incluye control de pausa/reproducción localizado. Con movimiento reducido o JavaScript desactivado muestra el poster; si el navegador bloquea la reproducción automática, se puede iniciar con el botón.

La sección Cultura corporativa de la Home reutiliza el mismo asset y poster, con controles nativos y reproducción manual. Usa `preload="none"` para evitar una descarga adicional antes de que el visitante lo reproduzca.
